# Hello

My name is **Zoravar Singh Kalkat**. I'm a medical doctor focused on traumatology and orthopaedics, but my research interests run broad. My current active research is:
 
- *Metabolomic Characterization of Fracture-related Infections*
- *The Effect of Endometriosis Surgery on Sexual Function*
- *Relationship between Ambient Air Pollution and Temperature with Acute Hospitalization due to Exacerbation of Cardiovascular Diseases*

Along the way, I also learned to program. I had been interested in it on and off for years and then I spent some time learning under a mentor (many thanks to [`@noxpardalis`](https://github.com/noxpardalis)).

Since then, it's been an incredibly useful part of my research, especially for cleaning and analyzing data, automating repetitive tasks, creating visualizations, and even lighthearted stuff like making [research questionnaires nice](/fsfi-en-first-page.pdf).

You can reach me at [contact@zoravar.eu](mailto:contact@zoravar.eu) if you want to collaborate on research!

## Programming

I build tools primarily in Rust, focusing on systems-level problems with an emphasis on security and reliability.

- [`memfd-secret`](https://github.com/ZorroTheRelentless/memfd_secret): A Rust crate wrapping the Linux `memfd_secret` syscall to securely store sensitive data in memory. The underlying memory is zeroed when the secret is dropped, and the crate includes full test coverage with property testing.

- [`shumai`](https://github.com/ZorroTheRelentless/shumai): A Linux CLI tool that automatically renews SSL certificates issued by Porkbun and exposes a health server. Built on top my memfd-secret crate.

- [`this website`](https://github.com/ZorroTheRelentless/astro-blog): A static site built with Astro from the ground up, without third-party themes. It features a custom layout system, custom multilingual routing, and a focus on clean typography and performance.
